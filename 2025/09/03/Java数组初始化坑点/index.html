  1. 为什么第一段代码需要初始化，第二段不需要初始化？

答案：

第一段代码中，当创建List<Integer>[] adj = new ArrayList[n]时，这只是创建了一个大小为n的数组，但数组中的每个元素都是null，而不是ArrayList实例。

而第二段代码，则已经创建了ArrayList实例。写成这样，你可能就会明白了。List<List<Integer>> res = new ArrayList<List<Integer>>();

Java语言中，声明一个数组，如果数据类型是引用类型，如果不初始化则默认为null。因此对于List<Integer>[]来说，如果在集合中添加元素，那必须进行new ArrayList<>()的初始化。

如果是基本类型，不初始化则默认为基本类型中的默认值。

以下是常见的数组创建后的默认值：

数据类型 数组创建后默认值 通常是否需要初始化 说明
String[] null 视情况而定 如果需要非null值，就必须初始化
List<>[] null 必须初始化 几乎总是需要可用的集合实例
int[] 0 通常不需要 0本身就是有意义的数值
boolean[] false 通常不需要 false本身就是有意义的布尔值
Object[] null 必须初始化 需要具体的对象实例
