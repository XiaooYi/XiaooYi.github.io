MySQL密码忘记怎么重置密码

发表于2025-06-09|更新于2025-07-29|基础
|字数总计:146|阅读时长:1分钟|阅读量:

一个可能的原因是 my.ini 配置文件中添加了 skip-grant-tables 导致的，去掉即可。

因为好久没用忘记 mysql 的密码了，所以通过在 my.ini 中引入[mysqld] skip-grant-tables 选项来重置密码。   但是发现添加 skip-grant-tables 之后，启动 mysql 服务几秒钟后自动停止。删除该选项后，mysql 服务又可以启动，很是奇怪。最后通过命令行跳过验证重置密码成功：./mysqld –skip-grant-tables & 。具体可以参考https://www.runoob.com/note/27730  。
我的 mysql 版本是 8.0.39。
